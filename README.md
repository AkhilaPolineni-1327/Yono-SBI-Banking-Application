# SBI Banking App UI/UX

A mobile UI/UX redesign concept for a banking application created in Figma.

## Project Overview

The SBI Banking App is designed to provide users with a simple, clean, and user-friendly banking experience. The design focuses on easy navigation and accessibility for common banking activities.

## Features

* Splash screen
* Language selection
* Login screen
* Home dashboard
* Account information
* Banking services
* Easy navigation
* User-friendly interface
* Interactive prototype

UI/UX Design
